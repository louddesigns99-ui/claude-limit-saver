# "I keep hitting my limit": a 5-minute audit

Ask the person for (or look at) their current setup, then check these in order. Report the top 3
fixes only, each in one line with the exact action.

1. **Long chats.** Is most work happening in one or two huge chats? → Move each line of work into a
   project with a CONTEXT.md (chat-to-project.md); start new chats per task.
2. **No memory file.** Do they re-explain the project at the start of chats? → CONTEXT.md.
3. **Heavy model on routine work.** Drafting, formatting, following steps on the heaviest model? →
   Default tier for those; heavy only for new systems, strategy, design.
4. **Scheduled tasks on the default model** or with vague prompts? → Explicit model + a written
   procedure (scheduled-tasks.md).
5. **Polling.** Repeatedly asking "is it done yet?" → one scheduled check-in.
6. **Re-raised topics.** Same warnings or parked ideas coming back every chat? → PARKED /
   DELIBERATE / FINISHED markers in CONTEXT.md.
7. **Wrong tool.** Long web research or image work that another subscription does well? → hand off
   (handoff.md).
8. **Huge pasted files.** Whole documents pasted repeatedly? → put them in Project knowledge or the
   repo once, and refer to them.

Don't promise percentages. Suggest the person compare one normal week with one week after the
changes: how often they hit the limit, and how many messages a typical task took.
